# Career Path Simulator

## Overview

Career Path Simulator is a Python-based career recommendation system that helps users discover suitable career paths based on their existing skills.

The application analyzes user skills, calculates career match scores, identifies missing skills, evaluates career readiness, generates personalized learning roadmaps, and allows comparison between multiple career options.

## How It Works

1. User enters their existing skills.
2. The system compares skills against predefined career requirements.
3. Match scores are calculated for all available careers.
4. The best career option is identified.
5. Missing skills are displayed.
6. A personalized learning roadmap is generated.
7. Career readiness level is evaluated.
8. Reports are saved for future reference.
